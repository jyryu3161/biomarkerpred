# BioMarkerPred v0.5.0

This release replaces the legacy train-AUC workflow with a shared research engine used by both the desktop and CLI. It adds patient-grouped nested validation, frozen binary/Cox models, external evaluation/drift, persistent verified runs, report regeneration, measured-background ORA, ranked GSEA and interactive gene evidence.

## Installers and runtime

- Windows x64: `.msi` and NSIS `.exe`. Choose one installer.
- macOS: universal `.dmg` and `.app.tar.gz`.
- Linux x64: `.deb`, `.rpm` and `.AppImage`; the installed `.deb` is the native IPC gate.
- Docker engine: `jyryu3161/biomarkerpred:v0.5.0` (Linux amd64). The exact registry digest is recorded below.
- Source archive, per-platform verification records and `SHA256SUMS` are attached.

The desktop includes engine code/schema; it requires either a compatible local R runtime or Docker. In Settings select Docker, explicitly pull the versioned image, save settings and run the doctor. Local R remains available without Docker. Linux's Pixi lock and the separate Windows/Apple Silicon binary package lock are included in the source archive.

## Required gates for this published release

The publication workflow requires the same commit to pass scientific R acceptance, CLI/helper/pathway checks, frontend tests/lint/build, Rust/R/Docker integration, browser interactions and the installed production image test. It also requires:

- Windows Server 2022 x64 runner: silent installation of MSI and NSIS separately, real Tauri IPC doctor/QC/development/prediction using installed resources, exact identifiers and spaces/Korean data paths, binary/Cox CLI/report workflows, and real R PSOCK/taskkill termination. Edge WebDriver is matched to the runner's WebView2 runtime; the detected versions are retained in workflow evidence. This is not a claim that every Windows desktop/security configuration was tested.
- Linux x64 runner: installed Debian package, real native IPC and R analysis, plus engine/resource/hash verification. RPM and AppImage are built; their installation is not independently exercised by this gate.
- Apple Silicon macOS runner: binary/Cox R workflows, native Rust tests, mounted DMG resource verification and actual application launch. The universal Intel slice is built but not executed. Native macOS WebDriver IPC is not tested with this project's tauri-driver route.

## Signing, migration and scientific limits

These packages are unsigned/unnotarized: Windows may show SmartScreen/unknown-publisher prompts; macOS Gatekeeper may block downloaded apps. No certificate or notarization credential is bundled. Follow local software approval policy rather than disabling system-wide protections.

Old incomplete model files require retraining. Legacy Streamlit, best-seed/train-AUC monoliths, coexpression and drug-score workflows are retired with migration messages. Conditional bootstrap intervals do not include full model-selection uncertainty. Functional association networks and disease-gene scores do not establish clinical utility or causal drug response. Use separately collected external cohorts for validation.
